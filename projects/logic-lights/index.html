    How to play / gate rules

Click an input like [A:0] to flip it (or press its letter).
(?) is a hidden light. Check reveals them:  (*) on   ( ) off

AND   on only when both inputs are on
OR    on when at least one input is on
XOR   on when exactly one input is on
NAND  off only when both inputs are on
NOR   on only when both inputs are off
NOT   flips its input
